# Calysta

> Calysta, Inc. is a cellular agriculture company founded in 2012, headquartered in San Mateo, California,
> with operations in Memphis, Tennessee (NouriTech), Wilton/Teesside in the United Kingdom (Calysta UK Ltd.)
> and Singapore (Calysta Asia Pte Ltd.). It produces protein ingredients via a patented gas-fermentation
> platform in which a naturally-occurring microorganism converts carbon and energy into a non-GMO
> single-cell protein, using no arable land and no plant or animal inputs. Calysta publishes **no public
> API, developer portal, SDK, or machine-readable specification** — its fermentation platform is
> industrial process technology sold as physical protein ingredients, not software offered to developers.

## API surface

Calysta has no public API surface. Probed 2026-08-09 against `https://calysta.com`. The host answers
every unknown path with a soft 404 — HTTP 200 carrying the 148,659-byte homepage — which was confirmed
with a random control path, so those 200s are not evidence of a resource. Verified against that control:
`/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc`,
`/graphql`, `/apis.json`, `/.well-known/agent-card.json`, `/.well-known/agent.json`,
`/.well-known/api-catalog`, `/.well-known/openid-configuration`, `/.well-known/oauth-authorization-server`,
`/.well-known/oauth-protected-resource` and `/.well-known/ai-plugin.json` all return the homepage, not a
resource. `/llms.txt` and `/.well-known/security.txt` return a genuine HTTP 404. The hosts `api.`,
`developer.`, `developers.`, `docs.`, `portal.` and `app.calysta.com` do not resolve (NXDOMAIN). The
complete `wp-sitemap.xml` (33 pages) contains no developer, documentation, or API page.

The site runs WordPress and exposes the stock WordPress REST API at `https://calysta.com/wp-json/`
(HTTP 200, 273 routes). Every namespace there is WordPress core or a third-party plugin — `wp/v2`,
`oembed/1.0`, `elementor/*`, `wordfence/v1`, `wpe/cache-plugin/v1`, `redirection/v1`. There is no
first-party Calysta namespace, so this is content-management plumbing for the marketing site rather
than a product API, and it is not recorded as an API surface.

A GitHub organization exists at `https://github.com/Calysta` with a single 2016-era Ruby repository
(`zProject`) whose homepage field points at `project.calysta.com`, a host that does not resolve. The
organization publishes no name, email, website or public members, so it is not attributable to this
company and is not wired into the profile.
